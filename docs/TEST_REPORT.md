- 차이: sample1 BMI의 원문 단위 `kg/m²`가 `kg/m2`로 반환됨. 앱은 원본 응답을 그대로 보여주며 임의 교정하지 않습니다.
- sample4 복용 일수 누락은 이번 실행에서 재현되지 않음. 한 번 통과한 것으로 영구 해결을 주장하지 않습니다. 이후 누락 발생 시 자동 보충하지 않고 확인 필요 표시 및 일정 생성을 차단합니다.

## 자동 테스트
